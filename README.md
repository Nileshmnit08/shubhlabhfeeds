# Shubh Labh Static Website — First Implementation

A standalone, framework-free static website starter for the Shubh Labh public brand website.

## Files
- `index.html` — six-section public website and navigation
- `styles.css` — responsive visual system, transitions, and reduced-motion support
- `script.js` — mobile menu, sticky header, scroll reveals, active navigation
- `.gitignore` — repository hygiene for OS files, IDE metadata, and temporary logs
- `CONTENT-GAPS.md` — verified business content audit and asset request list
- `DEPLOYMENT-READINESS.md` — static deployment readiness assessment and release checklist

## Preview locally
Open `index.html` directly in any modern browser. Alternatively, run a local static server:
- With Node.js: `npx serve .`
- With Python: `python -m http.server 8000` (visit `http://localhost:8000`)

## Current limitations / pre-launch checklist
- External Unsplash images and Google Fonts require internet access. Replace with approved Shubh Labh brand assets before launch.
- Product visuals are illustrative CSS mockups, not actual packaging photography.
- Confirm all product names and descriptions against approved labels/specifications.
- Add verified official phone, email, address, logo and company details.
- The WhatsApp link opens a prefilled generic message; configure an official business number before launch.
- No enquiry submissions are stored. This is intentionally static.
- Login links directly to https://shubhlabh-crm.vercel.app/.
- No deployment or domain changes have been made.
